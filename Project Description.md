## 📌 **Project Description**

The **Basic Image Classifier** is a desktop-based application developed using Python and deep learning techniques to automatically classify images into predefined categories. The system uses powerful frameworks like TensorFlow and Keras for building and training machine learning models, while Tkinter is used to provide an easy-to-use graphical user interface.

The application allows users to load their own dataset, train a model, and make predictions on new images without requiring advanced programming knowledge. It supports two types of models: a custom Convolutional Neural Network (CNN) and a transfer learning model based on MobileNetV2, which improves accuracy especially for smaller datasets.

The system performs image preprocessing such as resizing and normalization before feeding the data into the model. During training, it monitors performance using metrics like accuracy and loss. After training, users can evaluate the model using confusion matrices and classification reports.

Additionally, the application enables real-time image prediction, displaying the predicted class along with confidence scores. It also provides features like saving and loading trained models for future use.

Overall, this project demonstrates how deep learning can be integrated with a user-friendly interface to create an efficient and practical image classification system suitable for educational and real-world applications.
